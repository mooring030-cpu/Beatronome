# Beatronome v0.17.4 — 안정화 패치 (2026-11-22)

## 핵심 변경

사용자 요청에 따라 **AI STEM MIXER / 악기별 AI 분리 기능을 완전히 제거**했습니다. 부분 비활성화가 아니라 화면·JS·Worker·모델 호출·PC AI 서버·오프라인 캐시 등록을 삭제했습니다. 재도입 예정 기능도 아닙니다.

- `AI STEM MIXER` 메뉴와 관련 팝업/진단/PC 연결 안내 제거
- 브라우저 ONNX·WebAssembly 분리 모델 로딩 및 PC AI 엔진 삭제
- MY FILE 재생 그래프에서 스템 전용 분기 제거; 원본 음악 단일 신호 처리
- PWA 서비스워커 v0.17.4 캐시로 교체

## 유지된 주요 기능

- 메트로놈: BPM, 박자/분모/분할, TAP, Meter Chain, 고급 훈련, 오디오 복구
- MY FILE: **음악 전체 볼륨 0~100%**, 재생/일시정지, Speed, Key, 파형, Loop, 마커, 메트로놈 함께 재생/클릭만 끄기, 수동 첫 박 동기화
- YouTube: 영상 선택/초기화, mm:ss Loop, Speed, 메트로놈 동시재생, 첫 박 수동 동기화
- Groove, Tuner, 프리셋, 루틴, 연습 기록, 백업/복원, Cloud Sync 및 기존 사용자 저장값

## GitHub Pages 배포 방법

1. ZIP을 압축 해제하고 기존 Beatronome 프로젝트의 파일들을 새 파일로 교체합니다.
2. **예전에 올린 다음 파일/폴더는 GitHub 저장소에서도 직접 삭제하세요.** ZIP 덮어쓰기만으로는 삭제되지 않습니다: `stem-separation.js`, `stem-worker.js`, `fix-v0173.css`, `AI_BACKEND/` (폴더 전체).
3. Commit → Push origin. 배포 완료 후 앱을 완전히 닫았다가 다시 실행하고 **v0.17.4**로 바뀌었는지 확인합니다.
4. MY FILE에서 파일을 불러온 후 `음악 볼륨` 슬라이더를 움직여 소리 크기와 저장을 확인합니다.

> 저장키는 기존과 동일해 설정을 초기화하지 않습니다. 로컬로 불러온 음원 파일은 브라우저가 자동 보관하지 않으므로 종전과 같이 파일 재선택이 필요할 수 있습니다.
