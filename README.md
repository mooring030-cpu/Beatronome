# Beatronome v0.4 - Groove Engine

Beatronome is a browser-based PWA metronome and rhythm trainer.

## v0.4 new features
- Drum Groove Engine
- Playback mode: METRO / DRUM / BOTH
- 16-step drum pattern editor
- 8 instruments: Kick, Snare, Closed HH, Open HH, Ride, Rim, Clap, Cowbell
- Individual instrument mute and volume
- Drum kits: Studio, Vintage, Jazz, Funk, Electronic, Brush, Lo-Fi
- Genre library: Rock, Jazz, Funk, Blues, Latin, Pop, R&B
- Multiple ready-to-use groove presets for each genre
- Swing control
- Humanize control
- Drum Dropout control
- Groove settings are included in user presets

## Existing features retained
- BPM 30-300, drag, wheel, long-press +/- and rotary dial
- Tap Tempo
- Accent / Normal / Mute beats
- Subdivision
- Meter Chain
- Per-meter repeat bars (1-32)
- Random Mute
- Internal Clock
- Auto Tempo
- Gradual Mute
- Practice Timer
- Click sound selector
- PWA install / offline cache / wake lock

## GitHub Pages update
1. Extract this ZIP.
2. Copy every file into the root of the existing Beatronome repository and overwrite old files.
3. GitHub Desktop -> Commit to main.
4. Push origin.
5. Open the GitHub Pages site and refresh once. v0.4 uses a new service-worker cache and versioned JS/CSS URLs.

Current custom Tempo-style metronome sample audio is intentionally not included yet. It can be patched later when the reference recording is provided.
