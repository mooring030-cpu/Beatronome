## 2026-11-21 v0.17.2 UX 및 구현 결정

- YouTube 외부 Premium 계정/광고 안내나 외부 보기 버튼은 제거; 공식 iframe 광고 동작에 인위적으로 개입하지 않음.
- LOOP는 `mm:ss` 중심으로 노출하되 내부 저장은 초 단위 유지(기존 데이터 마이그레이션 불필요).
- YouTube 연습은 영상 좌측 + 직접 클릭 ON/OFF/첫 박 수동 보정 우측(큰 화면), 작은 화면은 바로 아래. 속도 슬라이더는 접기.
- MY FILE도 명시적 클릭 OFF/전체 음원 볼륨과 가까운 수동 동기화·접이식 AI 믹서 우선.
- 메인 Meter Chain은 QUICK SETUP 상단에 배치하되 두 기능 모두 기존 상태값 유지.
- AI는 원본 전체 구간 6파트. 서버로 로컬 음원을 전송하지 않고 Worker에서 처리. 고용량 모델의 메모리 한계를 거짓으로 '해결'로 보고하지 않음.


# v0.17.0 개발 결정 (2026-11-21)

- 사용자의 요청대로 31개 과제를 단일 버전으로 통합하되 **물리 기기/실계정 검증이 없어 확정 안정 릴리스로 표시하지 않는다.**
- 데이터 저장키와 소스 파일명을 유지하여 기존 PWA 로컬 데이터를 보존하고, Service Worker/asset 버전만 0.17.0으로 올린다.
- 예약 WebAudio 클릭을 취소·재스케줄하여 변경 시점 정책(즉시/다음 박/다음 마디)을 제공한다.
- YouTube/로컬 Backing은 영상·음원 파형으로 BPM 자동 분석을 수행하지 않는다. ±500ms 수동 보정은 청각 기반 조절로 명시한다.
- 기존 `.css` 파일은 보수·이력 소스로 보존하고 런타임에만 한 개 `beatronome.bundle.css` 로딩.
- 과거 버전 QA 스크립트는 `HISTORICAL_TESTS/`에 격리하고 새 버전에는 `QA_V0170_TESTS.js`만 직접 실행한다.
- Cloud 동시 편집은 서버 원자적 병합이 없으므로 충돌 시 원격 상태를 보존·파일 내보내기하며 동시 변경 시 완전 무손실을 약속하지 않는다.


### 2026-11-21 — Stem separation & YouTube Premium 경계
- YouTube IFrame API 정책과 CORS 경계를 존중한다. 광고를 숨기거나 프레임에서 오디오/쿠키를 추출하지 않는다.
- 저작권/사용권한 있는 **MY FILE** 오디오로만 AI 분리를 수행한다. 원본 음악은 외부 서버로 업로드되지 않는다. 모델·런타임은 사용자가 클릭할 때에만 외부 CDN에서 다운로드한다.
- 모델 메모리 사용량이 커 PC 우선 기능으로 안내하고, Apple 모바일은 실험적 기능으로 처리한다.
- Loop는 영상 위 접이식 패널에서 초를 직접 입력하거나 현재 위치로 지정할 수 있게 한다.
