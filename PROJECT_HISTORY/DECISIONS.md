## 2026-11-21 · v0.16.9 설정 접근성/UI 원칙
- 모바일/태블릿/PC 공통 메트로놈 메인에 **박자/분모 숫자 선택 → 작은 TAP → 분할**을 한 행에 배치한다. BPM ±1 버튼은 별도로 유지한다.
- 클릭 사운드/고급 기능 전환/FOCUS는 팝업 없이 접근하도록 공개한다. Count-in, 화면 Pulse, 진동은 고급 기능에 배치한다.
- Meter Chain은 설정이 아니라 메인에 독립 카드로 유지하고, 선택된 단계의 숫자 편집과 직접 새 단계 추가를 모두 제공한다.
- iOS 롱프레스 선택 차단은 **조작 가능한 UI**에만 적용하고 URL/검색/로그인 등 편집 입력의 복사 기능은 보호한다.
- 기존 프리셋/설정 스키마·오디오/YouTube/클라우드 로직을 보존하고 버전별 신규 CSS 레이어를 추가한다.
