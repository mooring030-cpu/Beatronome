- B-03 타이머 백그라운드: deadline watchdog 및 복귀 정산, 모의 통과 / iOS 미검증

## 실제 기기 확인 전에는 종료할 수 없는 문제

- **R-01/R-02 iOS 백그라운드·재생 무음:** 오디오 복구와 예약 로직 개선, 실기기 재생 음질·완전 무음 없음 검증 필요. OS가 중단하는 경우는 기술 한계.
- **R-03 YouTube + 메트로놈:** 통합 버튼 모의 통과, 실제 iframe·iOS 오디오 포커스 미검증.
- **R-04 로컬 Backing:** 사용자 제스처 로직 변경, 실제 미디어/애플 기기 미검증.
- **R-05 BPM/분할 라이브 전환:** 취소·재예약 로직 구현 및 모의 통과, 청음 검증 필요.
- **R-06 iOS 롱프레스:** 기존 차단 코드 유지, 진짜 iOS 화면 확인 필요.
- **R-07 Supabase 2기기:** 충돌 감지/백업 기능 개선, 실서비스 테스트 미검증.
- **R-08 PWA 캐시:** 정적 버전/리소스 검사 통과, 실제 배포·업데이트 미검증.
- **R-09 YouTube 25~200%:** 요청/실제 표시, 실영상 속도 확인 필요.
- **R-10 장시간·블루투스·기기 회전:** 실기기 30~60분 연속 테스트 미검증.

**판정:** v0.17.0 코드 수정·가상 테스트 완료. 하드웨어 검증 미완료이므로 '모든 환경에서 버그 없음'은 아님.
