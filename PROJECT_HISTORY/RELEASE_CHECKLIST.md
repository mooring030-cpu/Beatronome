## 설치/배포
1. 기존 Beatronome GitHub 저장소를 백업합니다.
2. ZIP 루트의 실행 파일 전체를 기존 저장소 루트에 덮어씁니다. 신규 **`fix-v0169.css`**, 수정된 `app.js`, `index.html`, `sw.js`를 반드시 포함합니다.
3. Commit 후 Push origin하고 GitHub Pages 배포 완료를 확인합니다.
4. 기존 PWA를 완전히 종료한 후 다시 열어 화면 상단 **v0.16.9**을 확인합니다. 이전 화면이 남으면 새 배포 버전의 SW 설치 상태를 점검합니다.
5. 설정값이 그대로 유지되면서 박자 7/8, 분할 3연음, 고급 Count-in 2마디가 정상 작동하는지 확인합니다.
