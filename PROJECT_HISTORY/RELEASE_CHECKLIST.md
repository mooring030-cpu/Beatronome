## 배포 과정
1. 현재 GitHub Pages 저장소 전체를 백업한다.
2. 이 ZIP의 **루트 파일 전체**를 저장소 같은 위치에 덮어쓴다. 변경점에 **새 fix-v0168.css 파일**이 반드시 포함되어야 한다.
3. GitHub Commit → Push origin 후 Pages 배포 성공을 확인한다.
4. 연습 중인 세션을 중단시키지 않도록 종료 후 앱/탭을 완전히 닫고 재실행한다.
5. 화면 상단 `v0.16.8` 표기와 앱 오프라인 상태를 확인한다.
