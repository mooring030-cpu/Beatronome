## 감사 31건 대응 현황

### B-01~B-07 — 직접 확인했던 코드 결함 7건

- B01 (완료): 드럼 Groove OFF 값(0) 보존. 새/없는 스텝만 기본패턴 사용. Node VM 검증.
- B02 (완료): Undo 세 함수 및 5초 UI 구현, BPM/박자/드럼/프리셋/백업 복원 흐름 확인.
- B03 (부분 검증): 연습 종료/루틴 전환을 Date.now 기반, 500ms watchdog과 복귀·스케줄러 체크로 정산. iOS 백그라운드 강제정지는 검증 필요.
- B04 (완료): 전체/선택형 JSON 백업 스키마 2, Backing 포함, 미리보기·롤백, 브라우저 선택복원 검증.
- B05 (완료/실서비스 미검증): YouTube API 로드 오류 시 Promise 해제·타임아웃/Retry. 재시도 모의 통과.
- B06 (완료): 현재 버전 QA를 단일 러너로 관리, 과거 버전 숫자 하드코딩 스크립트는 보존하되 격리.
- B07 (완료): UX 및 Quality 패널 모두 `BeatronomeAPI.getVersion()` 참조.

## 외부 QA 결론

**코드 구현과 자동 QA는 통과했습니다. 그러나 모든 버그가 실제 Apple 기기 및 실서비스에서 제거되었다고 확인할 근거는 없습니다.** iOS 백그라운드 재생은 OS 정책에 의해 제한될 수 있으며, YouTube iframe과 독립 Web Audio 두 소리의 샘플 단위 동기화는 불가능합니다. Cloud Sync 역시 네트워크 동시쓰기 충돌이 완전히 원자적으로 해결되는 구조가 아니므로, 양쪽 데이터 보존·복구 중심으로 개선했습니다.

기기별 테스트 절차와 통과 기준은 `HARDWARE_QA_CHECKLIST.md`에 있습니다.
