# Beatronome v0.17.0 실제 기기·서비스 QA 체크리스트

**중요:** 아래 테스트는 아직 실제 기기에서 수행되지 않았으며, 자동 검사 통과와 구분합니다. 테스트할 때는 실행 기기·OS·브라우저 버전·시간·스크린레코딩/청음 기록을 적습니다.

| H02 | iPhone 홈 화면 PWA | START → PDF/다른 앱 2분 → 복귀 → 5분 추가 | OS 허용 범위에서 템포 변화·박 튐 최소화. 중단되면 복구 버튼 및 상태 확인 | 미실시 |
