# Beatronome v0.17.3 품질검사 — 2026-11-21

## 사용자 보고와 진단

v0.17.2의 `AI 분리 실패: 브라우저 메모리 또는 WebAssembly 제한` 오류는 기존 ONNX WASM 경로가 모델 초기화 또는 추론 도중 중단되었음을 의미합니다. v0.17.2의 `Aborted()` 에러 분류만으로 실제 메모리 부족인지, 해당 그래프의 WASM 초기화 오류인지는 특정할 수 없습니다. 136MB fp16weights 모델은 다운로드만 줄일 뿐 런타임 메모리는 동일하며, 제작자 자료의 네이티브 6스템 추론 메모리 약 1.1GB는 브라우저의 원곡 PCM, 출력 오디오, 런타임 추가 부담을 포함하지 않습니다.

## 변경 사항

1. **PC 네이티브 AI 대체 경로:** `AI_BACKEND/server.py`에서 CPU Demucs 6스템을 실행하고 같은 로컬 주소에서 앱과 REST API 제공. GitHub Pages의 정적 페이지 자체로 Python AI를 실행하는 것은 불가능하므로 선택형 PC 서비스로 분리.
2. **UI 자동 연결:** `http://127.0.0.1:8765/`에서 실행 시 `PC AI 연결됨` 표시 후 전곡 6파트 작업 요청, 폴링, 6개 MP3 회수, 기존 Mixer에 연결. 기존 브라우저 경로는 그대로 남김.
3. **안전성:** API의 입력 확장자/300MB 제한, 임의 악기 경로 접근 제한, 다른 출처의 POST/DELETE 방지, 완료된 결과 삭제, 작업 중단, 원본 데이터 유지.
4. **오류 상세:** 기존 WASM `Aborted()`를 무조건 확정적인 메모리 원인으로 안내하지 않고 별도 기술 오류 상세를 볼 수 있도록 함.
5. **기존 앱 보존:** 메트로놈·YouTube·MY FILE의 저장키/동기화/기존 UI 배치 유지. CDN 가중치와 Demucs 네이티브 모델 파일은 ZIP에 포함되지 않음.

## 아직 검증하지 못한 것

- **실제 6스템 추론 (미검증):** 이 환경에서 Hugging Face 모델 및 의존 패키지를 외부 다운로드해 실제 30초/3분 음원을 분리하지 못했습니다. 네이티브 서버가 이를 보장한다고 주장하지 않습니다.
- **Windows 사용자 설치 (미검증):** Python·FFmpeg 설치, 패키지 다운로드와 PyTorch의 장치별 실행 성공은 실제 PC에서 확인해야 합니다.
- **GitHub Pages:** 이 URL에서는 기존 브라우저 WASM이 계속 사용됩니다. PC 네이티브 AI를 사용하려면 **GitHub 주소가 아닌 PC 로컬 앱 주소**를 열어야 합니다.
- **iPhone/iPad:** 기기 자체에 Python 서버가 없으므로 PC 로컬 엔진은 사용할 수 없습니다. 원격 서비스를 제공하려면 인증·HTTPS·서버·비용 관리가 추가로 필요합니다.
- **YouTube 광고/로그인/메트로놈 오디오:** 이번 수정의 대상이 아니며 이전 실기기 검증 상태를 유지합니다.

## 판정

**코드 변경과 서버 API 모의/회귀 테스트는 통과. `AI 분리 실제 성공`은 아직 미검증.** 브라우저 WASM 경로에서 재현된 하드 메모리 제한은 일반적인 Worker 교체나 새로고침만으로 해제할 수 없으므로, PC에서는 네이티브 백엔드로 분리해 검증하는 구조로 전환함.
